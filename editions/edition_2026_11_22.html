The ML Taxonomy: Supervised, Unsupervised & Self-Supervised

⏱ 2-Min Scan • Aurélien Géron: Hands-On ML

Machine Learning systems break down into four operational paradigms based on supervision type:

📖 Core Fundamentals Breakdown
  • Supervised Learning: Target labels are fed to the model (Linear/Logistic Regression, Random Forests, Deep Neural Nets). Used when you have ground truth.
  • Unsupervised Learning: Finding latent patterns without labels. Essential categories: Clustering (K-Means, DBSCAN), Dimensionality Reduction (PCA), and Association Rule Mining.
  • Self-Supervised & Metric Learning: Pretext tasks (e.g. contrastive loss, triplet loss) creating feature vectors where similar items cluster together.
🛠 Application to Your Upcoming Projects
  • Smart Gallery Cleaner App: Exact and near-duplicate images/videos are best solved with Unsupervised Perceptual Hashing (dHash) combined with Self-Supervised Embeddings (e.g. CLIP / MobileNet) and cosine similarity clustering.
  • Face Recognition for Cashback/Auth: Uses Siamese networks or ArcFace (Metric learning) where distance \( d(f(x_1), f(x_2)) \) is minimized for identical individuals.

The 3 Classic ML Pitfalls: Overfitting, Underfitting & Data Mismatch

⏱ 2-Min Scan • Interview Defense Knowledge

When an ML model fails in production, it almost always stems from one of three core design problems. Interviewers frequently test this to see if you can debug real-world pipelines:

⚠️ The Diagnosis Checklist
  • Overfitting (High Variance): The model learns noise in training data. Fixes: Simplify model (reduce parameters), Regularize (\(\ell_1, \ell_2\), Dropout), Gather more data, or clean labeling noise.
  • Underfitting (High Bias): The model is too simple to capture relationships. Fixes: Select a more powerful model, engineer better features, reduce regularization.
  • The "Data Mismatch" Trap (Crucial for Mobile Apps): Occurs when your training dataset distribution differs from real app user data (e.g. training your Gallery cleaner on clean web images, but users upload blurry phone photos under poor lighting). Solution: Keep a dedicated "train-dev" set drawn from the training distribution to isolate overfitting from true distribution shift.
Source: Hands-On ML (3rd Ed), Ch. 1, pp. 24–36 Interview Question Gold

LangChain vs. LangGraph: Why Cyclic State Machines Win

⏱ 1.5-Min Scan • Daily Prep Task

Standard LangChain pipelines use Directed Acyclic Graphs (DAGs) like `LCEL`, which are great for simple sequential steps (Prompt → Model → Output Parser). However, true autonomous agents require loops, conditional branching, and memory persistence.

🎯 Interview Key Takeaways
  • State: A central schema (TypedDict or Pydantic) that tracks all messages, tool outputs, and execution variables across steps.
  • Nodes & Edges: Nodes are Python functions that transform the State; Edges determine where execution routes next based on model tool calls or conditional checks.
  • Human-in-the-Loop (Interrupts): LangGraph can pause execution before critical actions (e.g. payment processing or sending external messages) and resume once approved.
